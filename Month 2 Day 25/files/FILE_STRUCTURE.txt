Quick Reference
===============

Starting the Server:
  uvicorn main:app --reload

API Base URL:
  http://localhost:8000

Documentation:
  http://localhost:8000/docs         (Swagger UI)
  http://localhost:8000/redoc        (ReDoc)
  http://localhost:8000/openapi.json (OpenAPI schema)

Key Endpoints:
  POST   /api/v1/books               - Create book
  GET    /api/v1/books               - List books (with filtering & pagination)
  GET    /api/v1/books/{id}          - Get specific book
  PUT    /api/v1/books/{id}          - Update book
  DELETE /api/v1/books/{id}          - Delete book
  
  POST   /api/v1/members             - Register member
  GET    /api/v1/members             - List members (with filtering & pagination)
  GET    /api/v1/members/{id}        - Get specific member

Filter Examples:
  ?author=frank                      - Find books by author (substring, case-insensitive)
  ?available=true                    - Find available books
  ?skip=20&limit=10                  - Pagination
  ?author=frank&available=true       - Combine filters

Error Format:
  {
    "error": {
      "code": "VALIDATION_ERROR",
      "message": "field: error details"
    }
  }

Status Codes:
  201 - Created (POST success)
  204 - No Content (DELETE success)
  200 - OK (GET/PUT success)
  400 - Bad Request
  404 - Not Found
  422 - Validation Error
  500 - Internal Server Error

Deployment
==========

Development:
  uvicorn main:app --reload

Production:
  gunicorn main:app --workers 4 --worker-class uvicorn.workers.UvicornWorker

Environment Variables:
  DATABASE_URL=sqlite+aiosqlite:///./library.db
  CORS_ORIGINS=http://localhost:3000,https://yourdomain.com
  ENV=development

Docker:
  FROM python:3.11
  WORKDIR /app
  COPY requirements.txt .
  RUN pip install -r requirements.txt
  COPY . .
  CMD ["uvicorn", "main:app", "--host", "0.0.0.0", "--port", "8000"]
