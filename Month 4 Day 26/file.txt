## ✅ Complete Auth Flow (5 Steps)

### 1️⃣ **Register** → User creates account
```
POST /auth/register
→ Email validated, password hashed with bcrypt
→ User created with role="member" (default)
→ 201 Created response
→ Rate limited: 10/minute
```

### 2️⃣ **Login** → User authenticates
```
POST /auth/login
→ Email looked up, password verified
→ JWT token generated (24-hour expiration)
→ Secure httponly cookie set
→ 200 OK + JWT token
→ Rate limited: 5/minute (brute force protection)
```

### 3️⃣ **Access** → User calls protected routes
```
GET /api/admin/users (Authorization: Bearer token)
→ JWT validated (signature + expiration)
→ Role checked (admin required)
→ 200 OK (if authorized) or 403 Forbidden (if not)
```

### 4️⃣ **Refresh** → Extend session before expiration
```
POST /auth/refresh
→ Old token validated, new token generated
→ Fresh 24-hour expiration
→ Token family rotated (detects replay)
→ 200 OK + new token
→ Rate limited: 10/minute
```

### 5️⃣ **Logout** → Terminate session
```
POST /auth/logout
→ Token revoked
→ Cookie cleared (Max-Age=0)
→ 200 OK
→ Cannot reuse token (401 on future calls)
```
