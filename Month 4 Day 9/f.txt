## 🔑 Key Concepts

**The Core Problem:**
- JWTs are stateless → can't revoke them mid-flight
- Solution: Short expiry (5-15 min) + refresh tokens in DB

**The Defense:**
1. Access tokens: Stateless JWT, expires quickly, no revocation needed
2. Refresh tokens: Hashed & stored in DB, revocable, rotatable
3. Reuse detection: Compare generation numbers, revoke entire family on reuse

**The Test:**
```
1. Login → Get tokens
2. Refresh → New tokens (old one invalidated)
3. Logout → Refresh token marked revoked
4. Try refresh again → 401 Unauthorized ✓
5. Try to use old token after logout → Still 401 ✓
```
