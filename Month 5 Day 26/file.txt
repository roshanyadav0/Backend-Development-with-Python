## Part 1: The endpoints

```
GET    /api/v1/categories/                 list (search, ordering, paginated)
POST   /api/v1/categories/                 create          (staff only)
GET    /api/v1/categories/{slug}/          retrieve
PUT/PATCH/DELETE /api/v1/categories/{slug}/                (staff only)

GET    /api/v1/posts/                      list: ?search= ?category= ?author= ?status= ?ordering= ?page= ?page_size=
POST   /api/v1/posts/                      create          (authenticated)
GET    /api/v1/posts/{slug}/               retrieve
PUT/PATCH/DELETE /api/v1/posts/{slug}/                     (author or staff)
```

Visibility rules:

- Anonymous users see **published** posts only.
- Authenticated users also see **their own drafts**.
- Staff see everything.
- Someone else's draft returns **404**, not 403, so its existence isn't revealed (Day 9).

## Part 2: Permissions

**posts/permissions.py** (consolidated from Days 10 and 13)
```python
from rest_framework import permissions


class IsAuthorOrReadOnly(permissions.BasePermission):
    message = "You can only modify your own content."

    def has_permission(self, request, view):
        return (
            request.method in permissions.SAFE_METHODS
            or bool(request.user and request.user.is_authenticated)
        )

    def has_object_permission(self, request, view, obj):
        if request.method in permissions.SAFE_METHODS:
            return True
        return request.user.is_staff or obj.author_id == request.user.id


class IsAdminOrReadOnly(permissions.BasePermission):
    message = "Only staff can modify this resource."

    def has_permission(self, request, view):
        return request.method in permissions.SAFE_METHODS or bool(
            request.user and request.user.is_staff
        )
```

## Part 3: Serializers

**posts/serializers.py**
```python
from django.contrib.auth import get_user_model
from django.urls import reverse
from rest_framework import serializers

from .models import Category, Post


class AuthorSerializer(serializers.ModelSerializer):
    class Meta:
        model = get_user_model()
        fields = ["id", "username"]


class CategorySerializer(serializers.ModelSerializer):
    post_count = serializers.IntegerField(read_only=True)   # annotated in the viewset

    class Meta:
        model = Category
        fields = ["id", "name", "slug", "post_count"]
        read_only_fields = ["id"]


class PostListSerializer(serializers.ModelSerializer):
    author = AuthorSerializer(read_only=True)
    categories = serializers.SlugRelatedField(
        many=True, slug_field="slug", queryset=Category.objects.all(), required=False
    )
    comment_count = serializers.IntegerField(read_only=True)
    like_count = serializers.IntegerField(read_only=True)

    class Meta:
        model = Post
        fields = [
            "id", "title", "slug", "author", "status", "categories",
            "comment_count", "like_count", "created_at", "published_at",
        ]
        read_only_fields = ["id", "created_at", "published_at"]


class PostDetailSerializer(PostListSerializer):
    comments_url = serializers.SerializerMethodField()

    class Meta(PostListSerializer.Meta):
        fields = PostListSerializer.Meta.fields + ["body", "comments_url", "updated_at"]
        read_only_fields = PostListSerializer.Meta.read_only_fields + ["updated_at"]

    def get_comments_url(self, obj):
        return reverse("posts_api:comment-list", kwargs={"post_slug": obj.slug})

    def validate_title(self, value):
        value = value.strip()
        if len(value) < 5:
            raise serializers.ValidationError("Title must be at least 5 characters.")
        return value

    def validate_categories(self, value):
        if len(value) > 5:
            raise serializers.ValidationError("A post can have at most 5 categories.")
        return value

    def validate(self, attrs):
        status = attrs.get("status", getattr(self.instance, "status", None))
        body = attrs.get("body", getattr(self.instance, "body", ""))
        if status == Post.Status.PUBLISHED and len(body) < 50:
            raise serializers.ValidationError(
                {"body": "A published post needs at least 50 characters."}
            )
        return attrs
```

Points worth understanding:

- **How categories get assigned.** `SlugRelatedField(many=True, queryset=...)` accepts `"categories": ["django", "python"]`. An unknown slug returns 400, since the field validates every value against the queryset. `PATCH` with `categories` **replaces the whole set**, and omitting it leaves the set unchanged.
- **`required=False`** lets a post be created with no categories.
- **Counts on create.** `comment_count` and `like_count` come from the viewset's `annotate`. A freshly created instance has no such attribute, and DRF skips read-only fields it can't find, so the 201 response simply omits them.
- **The list serializer is the light one.** Validation lives on the detail serializer, which `get_serializer_class` uses for every write.

import django_filters as filters

from .models import Category, Post


class PostFilter(filters.FilterSet):
    category = filters.ModelMultipleChoiceFilter(
        field_name="categories__slug",
        to_field_name="slug",
        queryset=Category.objects.all(),
        conjoined=False,                      # ?category=a&category=b means a OR b
    )
    author = filters.CharFilter(field_name="author__username", lookup_expr="iexact")
    created_after = filters.DateFilter(field_name="created_at", lookup_expr="date__gte")
    created_before = filters.DateFilter(field_name="created_at", lookup_expr="date__lte")

    class Meta:
        model = Post
        fields = ["status", "category", "author", "created_after", "created_before"]

## Part 5: ViewSets and routing

**posts/views.py** (only the parts that matter today; keep your `like`, `popular`, and comments code from earlier days where the `...` is)
```python
from django.db.models import Count, Q
from rest_framework import viewsets
from rest_framework.permissions import AllowAny, IsAuthenticated

from .filters import PostFilter
from .idempotency import IdempotentCreateMixin            # Day 23; drop it if you skipped that
from .models import Category, Post
from .pagination import StandardPagination
from .permissions import IsAdminOrReadOnly, IsAuthorOrReadOnly
from .serializers import (
    CategorySerializer, PostDetailSerializer, PostListSerializer,
)


class CategoryViewSet(viewsets.ModelViewSet):
    serializer_class = CategorySerializer
    lookup_field = "slug"
    permission_classes = [IsAdminOrReadOnly]
    pagination_class = StandardPagination
    search_fields = ["name"]
    ordering_fields = ["name", "post_count"]
    ordering = ["name"]

    def get_queryset(self):
        return Category.objects.annotate(
            post_count=Count(
                "posts",
                filter=Q(posts__status=Post.Status.PUBLISHED),
                distinct=True,
            )
        )


class PostViewSet(IdempotentCreateMixin, viewsets.ModelViewSet):
    lookup_field = "slug"
    pagination_class = StandardPagination
    filterset_class = PostFilter
    search_fields = ["title", "body", "author__username", "categories__name"]
    ordering_fields = ["created_at", "title", "comment_count", "like_count"]
    ordering = ["-created_at", "-id"]            # the id tiebreaker keeps pages stable

    def get_queryset(self):
        qs = (
            Post.objects
            .select_related("author")
            .prefetch_related("categories")
            .annotate(
                comment_count=Count("comments", distinct=True),
                like_count=Count("likes", distinct=True),
            )
        )
        user = self.request.user
        if user.is_staff:
            return qs
        if user.is_authenticated:
            return qs.filter(Q(status=Post.Status.PUBLISHED) | Q(author=user))
        return qs.filter(status=Post.Status.PUBLISHED)

    def get_serializer_class(self):
        return PostListSerializer if self.action == "list" else PostDetailSerializer

    def get_permissions(self):
        if self.action in ("list", "retrieve", "popular"):
            classes = [AllowAny]
        else:   # create, update, partial_update, destroy, like
            classes = [IsAuthenticated, IsAuthorOrReadOnly]
        return [cls() for cls in classes]

    def perform_create(self, serializer):
        serializer.save(author=self.request.user)

    # ... like, popular, retrieve cache, get_success_headers from earlier days ...
```

Why it's built this way:

- **Visibility lives in `get_queryset`**, so it applies to *every* action. An author can `PATCH` their own draft, and nobody else can even discover it.
- **`Q(...) | Q(author=user)` doesn't add a join**, so it can't duplicate rows.
- **`distinct=True` on both counts** is still required. Filtering by `categories__slug` adds a join, and without `distinct` the counts would multiply across joins (Day 8).
- **Category writes are staff-only**, but anyone can read them.
- **Deleting a category** removes its links to posts, **not the posts themselves**, because it's a ManyToMany relation.

**posts/management/commands/seed_blog.py** (create `management/__init__.py` and `management/commands/__init__.py` too)
```python
from django.contrib.auth import get_user_model
from django.core.management.base import BaseCommand

from posts.models import Category, Post


class Command(BaseCommand):
    help = "Create demo users, categories, and 30 posts (safe to re-run)."

    def handle(self, *args, **options):
        User = get_user_model()

        def user(name, **extra):
            u, created = User.objects.get_or_create(username=name, defaults=extra)
            if created:
                u.set_password("pass12345")
                u.save()
            return u

        alice = user("alice", email="alice@example.com")
        bob = user("bob", email="bob@example.com")
        user("staffer", email="staff@example.com", is_staff=True)

        cats = [
            Category.objects.get_or_create(name=n, defaults={"slug": n.lower()})[0]
            for n in ("Tech", "Django", "Python")
        ]
        for i in range(1, 31):
            post, _ = Post.objects.get_or_create(
                slug=f"sample-post-{i}",
                defaults=dict(
                    author=alice if i % 2 else bob,
                    title=f"Sample post {i}" + (" about the Django ORM" if i % 3 == 0 else ""),
                    body=("Lorem ipsum dolor sit amet. " * 3) + ("select_related rocks" if i % 5 == 0 else ""),
                    status=Post.Status.DRAFT if i % 4 == 0 else Post.Status.PUBLISHED,
                ),
            )
            post.categories.add(cats[i % 3])
        self.stdout.write(self.style.SUCCESS("Seeded."))
```

## Part 7: Automated tests

These lock in what you just checked by hand. They use LocMem (Day 15) and zero-padded titles, which avoids the Day 11 mistake where "number 7" also matched "number 17".

```python
from django.contrib.auth import get_user_model
from django.core.cache import cache
from django.test import override_settings
from rest_framework.test import APITestCase

from .models import Category, Post

User = get_user_model()
LOCMEM = {"default": {"BACKEND": "django.core.cache.backends.locmem.LocMemCache"}}
BODY = "x" * 60


@override_settings(CACHES=LOCMEM)
class PostCategoryAPITests(APITestCase):
    @classmethod
    def setUpTestData(cls):
        cls.alice = User.objects.create_user("alice", password="pass12345")
        cls.bob = User.objects.create_user("bob", password="pass12345")
        cls.staff = User.objects.create_user("staffer", password="pass12345", is_staff=True)
        cls.django = Category.objects.create(name="Django", slug="django")
        cls.python = Category.objects.create(name="Python", slug="python")
        for i in range(25):
            p = Post.objects.create(
                author=cls.alice, title=f"Post number {i:02d}", slug=f"post-{i:02d}",
                body=BODY, status=Post.Status.PUBLISHED,
            )
            p.categories.add(cls.django if i % 5 == 0 else cls.python)   # 5 django, 20 python
        Post.objects.create(author=cls.alice, title="Alice draft", slug="alice-draft", body=BODY)

    def setUp(self):
        cache.clear()

    # --- reading, filtering, searching, pagination ---
    def test_list_is_paginated_and_hides_drafts(self):
        r = self.client.get("/api/v1/posts/")
        self.assertEqual(r.status_code, 200)
        self.assertEqual(r.json()["count"], 25)
        self.assertEqual(len(r.json()["results"]), 10)

    def test_page_size_capped_and_bad_page_404(self):
        self.assertLessEqual(len(self.client.get("/api/v1/posts/?page_size=1000").json()["results"]), 50)
        self.assertEqual(self.client.get("/api/v1/posts/?page=99").status_code, 404)

    def test_filter_by_category(self):
        self.assertEqual(self.client.get("/api/v1/posts/?category=django").json()["count"], 5)

    def test_filter_by_several_categories_is_or(self):
        r = self.client.get("/api/v1/posts/?category=django&category=python")
        self.assertEqual(r.json()["count"], 25)

    def test_unknown_category_is_400(self):
        r = self.client.get("/api/v1/posts/?category=nope")
        self.assertEqual(r.status_code, 400)

    def test_search(self):
        self.assertEqual(self.client.get("/api/v1/posts/?search=number 07").json()["count"], 1)

    def test_search_filter_and_page_combine(self):
        r = self.client.get("/api/v1/posts/?category=python&search=Post&page=2&page_size=10")
        self.assertEqual(r.status_code, 200)
        self.assertEqual(r.json()["count"], 20)
        self.assertEqual(len(r.json()["results"]), 10)

    def test_ordering(self):
        r = self.client.get("/api/v1/posts/?ordering=title")
        self.assertEqual(r.json()["results"][0]["title"], "Post number 00")

    # --- visibility ---
    def test_draft_hidden_from_others_visible_to_author(self):
        self.assertEqual(self.client.get("/api/v1/posts/alice-draft/").status_code, 404)
        self.client.force_authenticate(self.bob)
        self.assertEqual(self.client.get("/api/v1/posts/alice-draft/").status_code, 404)
        self.client.force_authenticate(self.alice)
        self.assertEqual(self.client.get("/api/v1/posts/alice-draft/").status_code, 200)

    # --- writing ---
    def test_anonymous_cannot_create(self):
        r = self.client.post("/api/v1/posts/", {"title": "Nope nope", "slug": "nope", "body": BODY})
        self.assertEqual(r.status_code, 401)

    def test_create_with_categories(self):
        self.client.force_authenticate(self.bob)
        r = self.client.post(
            "/api/v1/posts/",
            {"title": "Brand new post", "slug": "brand-new", "body": BODY,
             "categories": ["django", "python"]},
            format="json",
        )
        self.assertEqual(r.status_code, 201)
        self.assertEqual(r.json()["author"]["username"], "bob")
        self.assertEqual(sorted(r.json()["categories"]), ["django", "python"])

    def test_unknown_category_slug_rejected_on_create(self):
        self.client.force_authenticate(self.bob)
        r = self.client.post(
            "/api/v1/posts/",
            {"title": "Another new post", "slug": "another", "body": BODY, "categories": ["ghost"]},
            format="json",
        )
        self.assertEqual(r.status_code, 400)
        self.assertIn("categories", r.json()["error"]["details"])

    def test_short_title_and_short_published_body_rejected(self):
        self.client.force_authenticate(self.bob)
        r = self.client.post("/api/v1/posts/", {"title": "Hi", "slug": "hi", "body": BODY}, format="json")
        self.assertIn("title", r.json()["error"]["details"])
        r = self.client.post(
            "/api/v1/posts/",
            {"title": "Valid title", "slug": "valid", "body": "short", "status": "published"},
            format="json",
        )
        self.assertIn("body", r.json()["error"]["details"])

    def test_patch_replaces_categories(self):
        self.client.force_authenticate(self.alice)
        r = self.client.patch("/api/v1/posts/post-00/", {"categories": ["python"]}, format="json")
        self.assertEqual(r.status_code, 200)
        self.assertEqual(r.json()["categories"], ["python"])

    def test_only_author_or_staff_can_modify(self):
        self.client.force_authenticate(self.bob)
        self.assertEqual(
            self.client.patch("/api/v1/posts/post-01/", {"title": "Hacked title"}, format="json").status_code, 403)
        self.client.force_authenticate(self.alice)
        self.assertEqual(
            self.client.patch("/api/v1/posts/post-01/", {"title": "Edited title"}, format="json").status_code, 200)
        self.client.force_authenticate(self.staff)
        self.assertEqual(self.client.delete("/api/v1/posts/post-02/").status_code, 204)

    # --- categories ---
    def test_category_list_public_with_published_counts(self):
        r = self.client.get("/api/v1/categories/")
        self.assertEqual(r.status_code, 200)
        counts = {c["slug"]: c["post_count"] for c in r.json()["results"]}
        self.assertEqual(counts, {"django": 5, "python": 20})

    def test_category_writes_are_staff_only(self):
        payload = {"name": "Tech", "slug": "tech"}
        self.assertEqual(self.client.post("/api/v1/categories/", payload).status_code, 401)
        self.client.force_authenticate(self.bob)
        self.assertEqual(self.client.post("/api/v1/categories/", payload).status_code, 403)
        self.client.force_authenticate(self.staff)
        self.assertEqual(self.client.post("/api/v1/categories/", payload).status_code, 201)

    def test_deleting_category_keeps_posts(self):
        self.client.force_authenticate(self.staff)
        self.assertEqual(self.client.delete("/api/v1/categories/django/").status_code, 204)
        self.assertTrue(Post.objects.filter(slug="post-00").exists())
```

Two notes on the tests:

- **The cache.** If you kept Day 15's anonymous list caching, `cache.clear()` in `setUp` is mandatory, and the anonymous tests each make only one list call. Test transactions never commit, so the invalidation callbacks don't run.
- **The `format="json"`** on writes is needed because `categories` is a list. The default multipart format handles lists awkwardly.

## Common gotchas

- **`PATCH` with `categories` replaces, not appends.** Clients that want "add one" need the stretch endpoint.
- **Inflated counts after a category filter**: the `Count()` calls lost `distinct=True`.
- **Duplicate posts in results**: a custom filter crossing a to-many relation without `.distinct()`. `ModelMultipleChoiceFilter` and `SearchFilter` handle this themselves.
- **Forgetting `format="json"`** in tests when sending lists.
- **`basename` assertion error**: `get_queryset()` without a `queryset` attribute needs `basename=` in `router.register`.
- **Filters treated as security**: `?status=draft` narrows results but never grants access. Visibility belongs in `get_queryset`.
- **Anonymous list cached with authenticated data**: only cache anonymous requests (Day 15).
- **`post_count` missing on create**: expected, since it's an annotation. Re-fetch if a client needs it.
- **Slug edits break links and orphan cache keys** (Day 16): consider freezing slugs after creation.
- **Leaving `PostListAPIView` from Day 7** in the urls shadows the router.
- **Seeding without Redis/worker running**: published posts try to queue emails, so expect logged errors.
