## 🎯 Key Concepts Covered

| Concept | What You Learn |
|---------|---|
| **Depends()** | FastAPI's dependency injection for route protection |
| **require_admin()** | Check role == "admin", raise 403 if not |
| **require_member()** | Check role in ["admin", "member"], raise 403 if neither |
| **401 vs 403** | 401 = not authenticated; 403 = insufficient role |
| **Route Guards** | Protect endpoints using FastAPI dependencies |
| **Admin Inheritance** | Admins can access all member routes |
| **Error Handling** | Generic messages, proper status codes |
| **Testing** | Test auth, authz, role inheritance |

## 📋 What You Can Do Now

✅ **Admin-only routes**
```python
@app.post("/api/books")
async def create_book(
    book_data: BookCreate,
    current_user: CurrentUser = Depends(require_admin)
):
    pass  # Only admin reaches here
```

✅ **Member-only routes**
```python
@app.post("/api/books/{id}/borrow")
async def borrow_book(
    book_id: str,
    current_user: CurrentUser = Depends(require_member)
):
    pass  # Member or admin reaches here
```

✅ **Proper error responses**
- Member tries admin route → **403 Forbidden**
- Unauthenticated tries protected route → **401 Unauthorized**
- Admin tries any route → **200 OK**
