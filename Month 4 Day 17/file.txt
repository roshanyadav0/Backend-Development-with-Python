## 🔐 What This Protects Against

### 1. Brute Force Attacks
```
❌ Without: Attacker tries 1000 passwords in seconds
✅ With 5/min: Would need 3+ hours (impractical)
```

### 2. Privilege Escalation
```
❌ Without: Attacker promotes all users to admin instantly
✅ With 5/min: Only 5 per minute (admin notices)
```

### 3. User Enumeration
```
❌ Without: Enumerate all users in seconds
✅ With 20/min: Takes 5+ minutes for 100 users
```

### 4. DOS (Denial of Service)
```
❌ Without: Server gets overwhelmed, crashes
✅ With limits: Each IP limited to 60-100/min, server stays up
```

### 5. API Scraping
```
❌ Without: Bot scrapes entire database instantly
✅ With 60/min: Takes hours to scrape everything (impractical)
```
